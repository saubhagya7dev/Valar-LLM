# Pilot data attribution

GitHub Advisory Database snapshots are attributed to **GitHub Advisory Database contributors**, licensed **CC BY 4.0**. The pinned repository revision, immutable source/license URLs and SHA-256 hashes are recorded in `sources.lock.json` and `manifest.json`. The full license is included at `sources/LICENSE.github-advisory-database.md`.

The included upstream advisory identifiers are GHSA-f82v-jwr5-mffw, GHSA-cpwx-vrp4-4pq7 and GHSA-9hjg-9r4m-mvj7. Original JSON snapshots are unmodified. Pilot requests select source passages, and reviewer inputs add explicitly synthetic repository observations and agent-authored upstream summaries. Those transformations are recorded; no annotation or output label is implied.

Original synthetic repository fragments, exercise narratives and document page assets are authored for Valar LLM and declared **CC0-1.0**: https://creativecommons.org/publicdomain/zero/1.0/. They describe no real repository, document owner or victim. Attribution and page/source hashes are retained even where CC0 does not require attribution.

These data licenses do not license future private uploads or every reference linked by an advisory. No third-party reference pages were copied. Model licenses are separate. This development-only pilot is not independently human-labeled gold, a model training set or a held-out evaluation release.
